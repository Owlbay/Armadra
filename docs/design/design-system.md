## §1 原则

| #   | 原则                   | 落点                                                                                                                                                   |
| --- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | 一套 token，两套主题   | 颜色、圆角、字号、动效、z 轴只从 `tokens.css` 取；深色是默认，浅色是 `:root[data-theme="light"]` 覆盖层；功能代码里不出现字面色值，也不写 `dark:` 分支 |
| 2   | 层级靠灰度，不靠线框   | 窗口底 → 面板 → 卡片三档表面 + 1px 低对比边；阴影只给真正浮起来的东西（节点、浮层、对话框）                                                            |
| 3   | 状态 = 文字 + 颜色     | 动画（脉冲、光晕、流动虚线）只是加强，`prefers-reduced-motion` 下全部静止而不丢信息                                                                    |
| 4   | 同一个对象，一种外观   | 画布节点、焦点页、会话视图、ACP 卡片、移动端都渲染同一份组件；平台差异只改布局常量与断点，不另做一套「简化版」                                         |
| 5   | 克制的文字             | 标签是名词或动词短语，没有句号；不解释后果的行不给脚注；空态只有一句话和一个动作                                                                       |
| 6   | 可达性是验收项         | 文字 ≥ 4.5:1，图形与焦点环 ≥ 3:1（WCAG 2.1 AA，1.4.3 / 1.4.11）；全部控件可键盘到达；触屏命中区 ≥ 44px；`forced-colors` 下保留系统焦点环               |
| 7   | Agent 颜色只属于 Agent | 七种内置 CLI 各一个固定色相，只用于标识「这是谁」；状态（运行、需要你、失败）用状态色，两套色永远不互相借                                              |

### §2.3 状态色

每个状态三个名字：`--<s>`（图形 / 圆点 / 边，≥3:1）、`--<s>-text`（文字，≥4.5:1，也用于叠在 `-soft` 上）、`--<s>-soft`（衬底）。深色主题下 `-text` 与图形色大多同值；浅色主题要分开。

| 状态        | 深色 图形 / 文字 / 衬底            | 浅色 图形 / 文字 / 衬底                   | 验证（文字对 card；文字对 soft） |
| ----------- | ---------------------------------- | ----------------------------------------- | -------------------------------- |
| danger      | `#ff453a` / `#ff9c94` / 16%        | `#d70015` / **改** `#b8000f` / 10%        | 深 6.9；5.9 ｜ 浅 6.9；5.8       |
| warn        | `#ff9f0a` / `#ff9f0a` / 16%        | **改** `#a35a00` / **新** `#8f4e00` / 10% | 深 6.8；5.0 ｜ 浅 6.5；5.7       |
| caution     | `#ffd60a` / `#ffd60a` / —          | **改** `#7f6000` / 同 / —                 | 深 9.9 ｜ 浅 5.9                 |
| success     | `#32d74b` / `#32d74b` / 16%        | **改** `#177a2e` / **新** `#15702a` / 10% | 深 7.3；5.3 ｜ 浅 6.2；5.4       |
| working     | `#d97757` / **新** `#e08a6e` / 18% | `#b8532f` / **新** `#9e4526` / 14%        | 深 5.3 ｜ 浅 6.3；5.5            |
| danger 实底 | `#d93025`（白字 4.8）              | `#d70015`（白字 5.4）                     |                                  |

状态语义映射（`StatusPill` 的 tone）保持：`working / attention(=warn) / failed(=danger) / queued / paused(=muted-foreground) / unread(=brand) / idle(=faint，只做圆点)`；新增 `done` = success，给会话行与工作流运行记录用。

- `--on-agent`（新）：实底头像上的字——深色主题 `#1c1c1c`（对七个标识色 ≥5.1），浅色主题 `#ffffff`（对七个压暗值 ≥4.5）。

| token              | 值                                           | 用途                                                                                  |

| `--dur-slow`       | 180ms                                        | 浮层进出                                                                              |

## §5 界面模式

每个模式给布局、组件、状态五元组（空 / 加载 / 错误 / 权限 / 离线）与文案键前缀。文案键按功能一个 i18n 模块（§7 列全）。

### §5.1 ACP 会话视图（节点体 / 焦点页）

```text
┌ 节点头部（不变：色点 标题 … 胶囊 允许/拒绝 ⋯）─────────────────────┐
│ ScrollArea                                                        │
│  ┌ 用户消息 ───────────────────────────┐  右对齐，--surface-raised │
│  └──────────────────────────────────────┘                         │
│  ┌ 助手消息 ──────────────────────────────────────────┐ 无底色     │
│  │ 段落 / 列表 / 代码块（Card raised, 12px code）      │ 悬停 ⋯     │
│  │ ▸ 思考（Collapsible，11px muted）                   │           │
│  │ ┌ 工具调用 Item ─────────────────────┐              │           │
│  │ │ ⌁ 读取 src/x.ts        StatusPill  ▸│              │           │
│  │ └────────────────────────────────────┘              │           │
│  │ ┌ 差异 Card ─────────────────────────┐              │           │
│  │ │ src/x.ts            +12 −3   打开  │              │           │
│  │ │ hunk（复用 DiffNode 行渲染）        │              │           │
│  │ └────────────────────────────────────┘              │           │
│  │ ┌ 权限 Card（--warn 左边 2px）───────┐              │           │
│  │ │ 运行 pnpm test                     │              │           │
│  │ │ [允许] [本次允许] [拒绝]  ButtonGroup│              │           │
│  │ └────────────────────────────────────┘              │           │
│  └──────────────────────────────────────────────────────┘           │
├ PromptBox ─────────────────────────────────────────────────────────┤
│ Textarea（自动增高 1–6 行）  [模式 Select ▾]  [发送]（icon, default）│
└────────────────────────────────────────────────────────────────────┘
```

- 发言人不写名字：用户靠右，Agent 靠左，头像只在焦点页 / 多 Agent 聚合视图里出现（`AgentAvatar 20`）。
- 工具调用行：图标按 kind（read / edit / execute / search / fetch），标题 13px，状态胶囊 `working / done / failed`；展开看入参与输出（`--surface-raised`，等宽 12px，最多 20 行后「展开全部」）。
- 权限卡：选项按 ACP 给的 kind 分组，`allow_*` 用 default，`reject_*` 用 outline；只有一个 Card 处于待答时它固定在 PromptBox 上方（`position: sticky; bottom`），其余滚走。头部的允许 / 拒绝继续答第一组。
- 切换视图：头部 `⋯` 里「会话视图 / 终端视图」打钩项；切换时节点体 120ms 淡入，尺寸不变。
- 状态：空 → `Empty`「向它说第一句话」+ 聚焦输入框；加载历史 → 三条 `Skeleton`；流式中 → 最后一条消息尾部一个 `Spinner 12`；错误 → 消息流尾部 `Alert destructive` 一行 + 「重试」；权限 → 上面那张卡；离线 → PromptBox 禁用，上方 `Alert`「已断开，正在重连」。
- 手机：同一组件铺满焦点页；PromptBox 坐在软键盘上（`100dvh`），模式 Select 收进「⋯」。

### §5.2 输出到画板

- 入口：助手消息悬停 / 长按出 `IconButton inline`「⋯」→ `DropdownMenu`：「落为便签」「落为白板文字」「代码块 → 编辑器」「Mermaid → 白板」；选中文字右键同样四项。
- 落成后：画布把相机 150ms 平移到新节点，节点带 `unread` 光晕一次；来源徽标见 §4。
- 状态：不可用项灰掉（没有代码块就没有「→ 编辑器」），不解释原因；失败 → sonner 一行「没有放到画板上」+「重试」。

### §5.14 更新与安装

- 设置 → 更新：一张 `SettingsGroup`，第一行「当前版本」只在这一页出现；状态集合按[更新设计](updates-and-service-install.md) §4.1，用一行文字 + 一个按钮表达，不做进度条以外的图形：下载中 → `Progress` + 「取消」；已下载 → 「重启并更新」default + 「稍后」ghost；失败 → `Alert destructive` + 「重试」。
- 托盘「重启以完成更新」与系统通知各一条，chrome 里不出现版本号或「有更新」角标。
- 服务安装（服务器壳）：同一页第二张分组：「注册为系统服务」Switch + 状态 `StatusPill`（运行中 / 已停止）。

### §5.15 集成设置：启动器警告与过期 worker

- 每个 CLI 一张 `SettingsGroup`：行「版本」（值 + 过旧时 `Badge destructive`「需要更新」+「查看命令」）、「启动器」（正常时无附加；异常时行尾 `Alert` 单行：「启动器与当前版本不一致」+「修复」）、「ACP」（已安装 / 「安装命令」复制钮）。
- 远端执行主机页：worker 版本与 core 不一致的行 → `Badge destructive`「过期」+「同步」。
- 原则：没有问题的行不出现任何提示；问题行的动作就是修复本身，不写解释段。

### §5.16 通用状态矩阵

| 状态 | 组件                                             | 文案形态                                 |
| ---- | ------------------------------------------------ | ---------------------------------------- |
| 空   | `Empty`                                          | 一句名词短语 + 一个 default 动作         |
| 加载 | `Skeleton`（列表 / 卡）或 `Spinner`（按钮 / 行） | 不写「加载中…」                          |
| 错误 | `Alert destructive`（行内）/ sonner（瞬时）      | 发生了什么 + 一个动作（重试 / 打开设置） |
| 权限 | `Badge outline` 替代按钮，或分区不出现           | 「等待驱动者」「只读」                   |
| 离线 | 顶部 `Alert`，输入禁用                           | 「已断开，正在重连」                     |

## §6 文案

- 按钮：动词或动宾（「保存」「重启并更新」「使用通行密钥」）；取消永远在左、主动作在右；危险动作用 destructive 且在 `AlertDialog` 里重复一次对象名（「停用「张三」？」）。
- 标签：名词，无标点；不写「请」「您」。
- 状态：两到四字（运行中 / 需要你 / 本轮失败 / 已排队 / 已暂停 / 未读 / 已完成）。
- 错误：先说发生了什么，再给一个动作；不写错误码；不猜原因。
- 不写：「预留」「未实现」「即将推出」「v1.2.3」（除关于 / 更新页）、英文夹杂（CLI 与品牌名除外）。
